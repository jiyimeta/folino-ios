# App Review Sample

This folder contains a sample score file for App Review.

Included file:

- `demo.mscz`

How to review:

1. Launch folino.
2. Import `demo.mscz` from the Files picker or share sheet.
3. Open the imported score in the reader.
4. Verify score viewing and playback features.

What this sample helps verify:

- MuseScore `.mscz` import
- Score display in the reader
- MIDI playback
- Per-part controls such as volume, mute, solo, and instrument selection
- A-B repeat
- Metronome
- Tempo control
- Background playback

Notes:

- The app does not require login.
- The sample file is provided only to help App Review test the import and playback flow quickly.
